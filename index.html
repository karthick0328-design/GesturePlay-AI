Geometric Recognition Rules

Supported Gestures & Key Mappings

GesturePlay AI uses normalized Euclidean finger extension ratios and vector angle heuristics for 100% deterministic, instant gesture detection.

🖐️
OPEN PALM Key [ W ]

All 5 fingers extended. Triggers full throttle acceleration in racing games or forward movement in FPS titles.

Rule: ext_count == 5 Action: Accelerate
✊
CLOSED FIST Key [ S ]

All fingertips curled into the palm. Triggers emergency braking, reverse drive, or crouch/shield mechanics.

Rule: ext_count ≤ 1 Action: Brake / Shield
👈
TILT LEFT Key [ A ]

Hand tilted toward the left (-120° to 120° vector angle). Smoothly turns vehicle left without touch.

Rule: angle > 120° Action: Steer Left
👉
TILT RIGHT Key [ D ]

Hand tilted toward the right (-60° to 60° vector angle). Smoothly steers vehicle to the right.

Rule: -60° ≤ angle ≤ 60° Action: Steer Right
✌️
TWO FINGERS Key [ SPACE ]

Index and middle finger extended (Peace sign). Activates nitrous boost, emergency handbrake, or jump.

Rule: index && middle Action: Jump / Nitro
🛡️
SAFE RELEASE Keys Up

When your hand exits the camera frame, GesturePlay automatically releases all held keys to prevent sticky key spamming.

Safety: Auto-debounce Action: Release All
Under The Hood

Computer Vision Pipeline

How a frame from your webcam transforms into an operating system keyboard stroke in under 15 milliseconds.

STAGE 01

Frame Acquisition

OpenCV captures raw 60 FPS video from the user's webcam, flips horizontally for natural mirror feel, and converts to RGB.

STAGE 02

MediaPipe 3D Mesh

Extracts 21 3D hand coordinates (wrist, knuckles, MCPs, fingertips) with sub-pixel landmark precision.

STAGE 03

Geometric Normalization

Computes Euclidean distance ratios and atan2 angles relative to palm bounding box, making detection distance-independent.

STAGE 04

Temporal Debounce

Stabilizes noisy transitions through a 4-frame FIFO buffer, eliminating jitter and rapid key repeat bugs.

STAGE 05

DirectX Automation

ActionMapper executes scan-code keypresses via PyDirectInput, sending hardware-level keystrokes directly into PC games.

PC Gaming Installation

Run Native Desktop Controller

To control games running on your PC (Steam, Xbox App, Epic Games, Emulators), run the Python desktop app locally.

Windows Terminal / PowerShell 
# 1. Clone the repository
git clone https://github.com/karthick0328-design/GesturePlay-AI.git
cd GesturePlay-AI

# 2. Install Python dependencies
pip install -r requirements.txt

# 3. Launch the GesturePlay AI Controller
python app/main.py
